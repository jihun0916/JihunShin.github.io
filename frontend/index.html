학교/작업용 컴퓨터에서 집 컴퓨터의 Ollama에 접속하세요. 작업 컴퓨터에는 설치 불필요!

🔗 현재 Ollama 설정

✨ 방법 1: Cloudflare Tunnel (추천 - 설치 불필요!)

집 컴퓨터에만 설정하면 학교/작업 컴퓨터에서 브라우저로 바로 사용 가능!

📋 집 컴퓨터 설정 (5분 소요):
  1. PowerShell을 관리자 권한으로 실행
  2. setup-cloudflare-tunnel.ps1 스크립트 실행
  3. 나오는 URL 복사 (예: https://abc-xyz.trycloudflare.com)
💻 학교/작업 컴퓨터 (설치 불필요):
  1. 이 페이지 접속 (GitHub Pages 또는 로컬)
  2. 위 입력창에 Cloudflare URL 붙여넣기
  3. "저장" → "연결 테스트" 클릭
  4. ✅ 모든 기능 사용 가능!
💡 장점: 학교 컴퓨터에 아무것도 설치 안 함, HTTPS 자동, 학교 방화벽 우회

📖 Cloudflare Tunnel 상세 가이드

자동 스크립트 사용법 (권장) 👈

1. 스크립트 실행:

# PowerShell (관리자 권한)에서:
cd C:\Users\신지훈\Desktop\homepage
.\setup-cloudflare-tunnel.ps1

2. URL 복사:

새 창에 표시되는 URL 복사 (예: https://abc-xyz.trycloudflare.com)

3. 완료!

스크립트가 자동으로:

  • cloudflared 다운로드
  • Ollama CORS 설정
  • 터널 시작
수동 설정 (고급 사용자)

1. cloudflared 다운로드:

Invoke-WebRequest -Uri "https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe" -OutFile "C:\cloudflared.exe"

2. CORS 설정:

[System.Environment]::SetEnvironmentVariable('OLLAMA_ORIGINS', 'https://*.trycloudflare.com,https://*.github.io', 'Machine')
taskkill /F /IM ollama.exe
ollama serve

3. 터널 시작:

C:\cloudflared.exe tunnel --url http://localhost:11434

🔄 방법 2: Tailscale (양쪽 다 설치 필요)

학교 컴퓨터에도 설치 권한이 있다면 이 방법도 가능합니다.

Tailscale 설정 가이드
  1. 양쪽 컴퓨터에 Tailscale 설치
    • Tailscale 다운로드
    • 같은 계정으로 로그인
  2. 집 컴퓨터 IP 확인
    • PowerShell: tailscale ip -4
    • 예시: 100.x.x.x
  3. CORS 설정
    • [System.Environment]::SetEnvironmentVariable('OLLAMA_ORIGINS', 'http://100.*.*.*:*,https://*.github.io', 'Machine')
  4. 작업 컴퓨터에서 사용
    • 위 입력창에 http://100.x.x.x:11434 입력

💡 팁

  • Cloudflare 추천 이유: 학교 컴퓨터에 설치 불필요, HTTPS 자동, 방화벽 우회
  • URL 유지: Quick Tunnel은 재시작마다 URL 변경됨 (영구 터널 설정 시 고정)
  • GitHub Pages: 어디서나 https://yourusername.github.io/homepage?research=true 접속
  • 집 컴퓨터: 항상 켜두거나 WakeOnLAN 설정 권장
