I am a PhD student at the KAIST Graduate School of Culture Technology, advised by Professor Sung-Hee Lee, after earning my Master's in the same department. Alongside research, I am the CEO of BerryHi, an XR startup building real-space community platforms. I hold a Bachelor's in Oriental Painting from Hongik University, complemented by an extensive curriculum in Computer Science.

My work lives at the intersection of Computer Graphics, Telepresence, Digital Humans, and Virtual Spaces — technologies that quietly enable people to understand one another across distance and difference.

🔑 Claude API 설정

📋 API 키 발급 방법

  1. console.anthropic.com 접속 및 회원가입
  2. 좌측 메뉴 → API Keys 클릭
  3. Create Key 버튼 클릭 → 키 복사
  4. 위 입력창에 붙여넣기 → 저장
💡 비용: Claude Sonnet 4 기준 입력 $3/100만 토큰, 출력 $15/100만 토큰. 논문 번역 1회 약 $0.01~0.05 수준.

✅ 장점

  • 어디서든 접속: 로그인만 하면 집, 학교, 카페 어디서든 사용 가능
  • 설치 불필요: 터널, Ollama, GPU 전혀 필요 없음
  • 고품질: Claude Sonnet 4 → 학술 번역/작문 최고 수준
  • API 키 보안: 키는 브라우저 localStorage에만 저장 (서버 전송 없음)

🔗 GitHub 저장소 설정

📋 설정 방법

  1. GitHub에서 private 저장소 생성 (예: paper-vault)
  2. Fine-grained Personal Access Token 발급 → Contents 권한 (Read & Write)
  3. 위 필드에 입력 후 연결 테스트
  4. Obsidian에서 같은 저장소를 Obsidian Git 플러그인으로 연결
💡 동기화 흐름: 웹앱에서 논문 추가/편집 → GitHub → Obsidian Git 자동 pull.
